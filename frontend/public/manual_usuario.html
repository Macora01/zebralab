1 Introducción y requisitos

ZebraLab es una aplicación web para diseñar etiquetas Zebra ZPL de forma visual, sin necesitar ZebraDesigner (solo disponible en Windows). Está pensada para usuarios de Mac con impresoras Zebra ZD220 conectadas via USB o red.

¿Qué puedes hacer con ZebraLab?

  • Diseñar etiquetas visualmente con texto, códigos de barras, imágenes y figuras
  • Guardar y reutilizar diseños como plantillas
  • Exportar archivos .prn compatibles con tu impresora Zebra
  • Imprimir en masa desde archivos CSV o Excel
  • Imprimir directamente desde el navegador sin descargar archivos (con el agente local)
  • Importar archivos .prn creados en ZebraDesigner u otras herramientas

Requisitos

Para usar la app web

  • Navegador moderno (Chrome recomendado)
  • Conexión a internet

Para imprimir directo

  • macOS con CUPS instalado
  • Python 3.7+
  • Agente local ejecutándose
  • Impresora Zebra instalada en CUPS
ZebraLab genera ZPL II a 203 dpi (8 dots/mm), el estándar de la Zebra ZD220. Los archivos exportados son compatibles con cualquier script Python que use lp -d NombreImpresora -o raw archivo.prn.

2.2 Lienzo (canvas)

El lienzo representa la etiqueta física en escala visual. Las coordenadas son en milímetros.

  • Mover elementos: arrastra con el mouse
  • Seleccionar: clic sobre el elemento
  • Eliminar: selecciona el elemento y presiona Delete o Backspace
  • Zoom: botones + y - en la esquina inferior derecha
  • Multi-up: si configuraste más de 1 columna o fila, las copias aparecen sombreadas — solo editas la primera
Si un elemento aparece con borde rojo, significa que se sale de los límites de la etiqueta y podría no imprimirse correctamente.

3 Elementos de etiqueta

3.1 Texto estático

Texto fijo que siempre imprime el mismo contenido.

PropiedadDescripción
ContenidoEl texto que aparecerá impreso
FuenteEstándar (0), Compacta (A), Bloque (B), Bold (D), Grande (F)
Altura (mm)Alto del texto en milímetros
Ratio anchoProporción ancho/alto del carácter (1.0 = normal, 0.5 = estrecho, 2.0 = ancho)
Rotación0°, 90°, 180° o 270°
X / Y (mm)Posición desde la esquina superior izquierda de la etiqueta

3.2 Texto variable

Un campo que se completa en tiempo de impresión con datos del CSV o manualmente. Usa la sintaxis {nombre_variable} en el ZPL.

Los nombres de variables solo pueden contener letras, números y guión bajo (_). Ejemplo: precio, codigo_producto, lote.

Variable especial: la variable llamada precio agrega automáticamente el símbolo $ al inicio del valor. Ejemplo: si el CSV tiene 9990, se imprime $ 9990.

Propiedades adicionales para códigos de barras lineales:

  • Altura (mm): alto de las barras
  • Mostrar texto humano: imprime el número debajo del código

Propiedades adicionales para QR:

  • Magnificación (1-10): tamaño de cada módulo del QR
  • Corrección de errores: L (7%), M (15%), Q (25%), H (30%)

3.5 Imágenes y logos

Sube una imagen PNG o JPG para incluirla en la etiqueta. La imagen se convierte automáticamente a blanco y negro (la impresora Zebra es monocromo).

  • Formatos: PNG, JPG, GIF, BMP, WEBP
  • Se recomienda usar imágenes con buen contraste (logos en negro sobre blanco)
  • Umbral B/N: deslizador para ajustar qué tonos se convierten a negro. Valores bajos = más negro, valores altos = más blanco
Para logos, usa una imagen PNG con fondo transparente o blanco y líneas negras bien definidas para obtener el mejor resultado.

4 Plantillas

Las plantillas permiten guardar diseños completos y reutilizarlos. Se almacenan en la nube (base de datos del servidor).

Guardar una plantilla nueva

  1. Haz clic en Plantillas en la barra superior
  2. En el campo "Guardar diseño actual", escribe un nombre descriptivo
  3. Haz clic en Guardar

Actualizar una plantilla existente

  1. Carga la plantilla (botón Abrir)
  2. Realiza los cambios en el editor
  3. Abre Plantillas y haz clic en Actualizar

Otras acciones

AcciónDescripción
AbrirCarga el diseño de la plantilla en el editor
DescargarDescarga el archivo .prn de la plantilla
DuplicarCrea una copia con el sufijo "(copia)"
EliminarBorra la plantilla permanentemente (pide confirmación)

Importar archivo .prn existente

Si tienes archivos .prn creados en ZebraDesigner u otras herramientas, puedes importarlos directamente:

  1. Abre Plantillas
  2. Haz clic en Subir .prn / .zpl
  3. Selecciona tu archivo
  4. El archivo queda disponible en la biblioteca con el icono de archivo .prn
Las plantillas importadas como .prn no son editables visualmente en el canvas. Se abren en un modal especial donde puedes completar variables, previsualizar e imprimir.

5 Vista previa

La vista previa genera una imagen real de cómo quedará la etiqueta al imprimir, usando el servicio Labelary.

  1. Haz clic en Vista previa en la barra superior
  2. Si tu diseño tiene variables, completa los valores de prueba en el panel izquierdo
  3. Haz clic en Regenerar vista previa para actualizar
  4. El panel derecho muestra la imagen y el panel izquierdo el código ZPL generado
Las variables sin valor se muestran entre corchetes en la vista previa (ej: [precio]) para que puedas identificar dónde aparecerán los datos.

6 Exportar archivo .prn

El botón Exportar .prn descarga el archivo ZPL listo para enviarlo a la impresora.

Usos del archivo .prn

  • Enviarlo directamente a la impresora desde Terminal:
    lp -d Zebra_ZD220 -o raw etiqueta.prn
  • Usarlo con el script Python original de BoaIdeia
  • Guardarlo para reutilizarlo en el futuro
Si el diseño tiene variables (campos {nombre}), el archivo exportado las incluirá sin sustituir. Usa el flujo de Lote CSV o el botón "Imprimir ahora" para sustituirlas automáticamente.

7 Impresión masiva (CSV / Excel)

La función de Lote CSV permite generar cientos de etiquetas personalizadas a partir de un archivo de datos, sin tener que editarlas una por una. Cada fila del archivo genera una etiqueta con sus propios datos.

7.1 Formato del archivo

ZebraLab acepta tres formatos:

FormatoExtensiónNotas
CSV separado por comas.csvSeparador automático (detecta , y ;)
Excel moderno.xlsxPrimera hoja del libro
Excel clásico.xlsPrimera hoja del libro

7.2 Estructura del archivo

El archivo debe tener una fila de encabezado (primera fila) con los nombres de las columnas, seguida de una fila por etiqueta:

ReglaDetalle
Primera fila = encabezadosLos nombres de columna se usan para el mapeo de variables
Una fila = una etiquetaSalvo que uses la columna de cantidad
Celdas vacíasSe tratan como texto vacío (no genera error)
Encoding CSVUTF-8 recomendado. Se aceptan tildes y ñ
NúmerosSe convierten a texto automáticamente

7.3 Ejemplos de archivos

Ejemplo 1 — Etiquetas de precio para productos

Para una etiqueta con variables {producto}, {precio} y {codigo}:

# archivo: precios_temporada.csv
producto,precio,codigo,cantidad
Bolsa tela S,4990,BT-001,50
Bolsa tela M,6990,BT-002,30
Bolsa tela L,8990,BT-003,20
Porta documentos,12990,PD-001,15

Este archivo generará 115 etiquetas en total (suma de la columna cantidad).

Ejemplo 2 — Sin columna de cantidad (1 etiqueta por fila)

# archivo: inventario.csv
nombre,lote,fecha
Producto A,LOT-2024-001,15/01/2025
Producto B,LOT-2024-002,22/01/2025
Producto C,LOT-2024-003,30/01/2025

Ejemplo 3 — Etiquetas con QR variable

# archivo: qr_urls.csv
nombre,url,cantidad
Catálogo 2025,https://boaideia.cl/catalogo,100
Instagram,https://instagram.com/boaideia,200
WhatsApp,https://wa.me/56912345678,150

Ejemplo 4 — Excel (.xlsx)

Mismo formato que CSV pero en un libro Excel. La primera fila debe ser los encabezados:

producto precio codigo_barras cantidad
Billetera cuero 15990 7800000001234 25

7.4 Mapeo de variables

Después de cargar el archivo, ZebraLab detecta automáticamente las variables en tu diseño ({variable}) y las columnas del archivo. Si los nombres coinciden, el mapeo es automático. Si no coinciden, puedes asignarlos manualmente con los selectores.

PANEL DE MAPEO
Variable del diseño→Columna del archivo
{producto}→▼ nombre_item (seleccionar)
{precio}→▼ precio ✓ (detectado)
{codigo}→▼ codigo_barras (seleccionar)
Si la columna se llama igual que la variable (mismo nombre, sin distinguir mayúsculas), el mapeo es automático. Nombra las columnas de tu CSV igual que las variables del diseño para ahorrar tiempo.

7.5 Columna de cantidad

Si necesitas imprimir más de una etiqueta por fila, agrega una columna con el número de copias. ZebraLab la detecta automáticamente si se llama cantidad, qty, cant o quantity. También puedes seleccionarla manualmente.

Nombre de columna aceptadoIdioma
cantidadEspañol
cantEspañol (abreviado)
quantityInglés
qtyInglés (abreviado)
Si la columna de cantidad contiene un valor no numérico o vacío, esa fila se imprime 1 vez por defecto.

Flujo completo de impresión masiva

  1. Diseña tu etiqueta con variables en el editor (ej: {nombre}, {precio})
  2. Haz clic en Lote CSV en la barra superior
  3. Sube tu archivo CSV o Excel
  4. Verifica el mapeo de variables (se hace automáticamente si los nombres coinciden)
  5. Selecciona la columna de cantidad si aplica
  6. Revisa la tabla de datos (muestra las primeras 5 filas)
  7. Haz clic en Vista previa para ver la primera etiqueta
  8. Haz clic en Descargar .prn para obtener el archivo con todas las etiquetas, o Imprimir ahora si tienes el agente activo

8 Agente local de impresión

El agente local es un pequeño programa Python que corre en tu Mac y permite que ZebraLab envíe trabajos directamente a la impresora Zebra sin descargar archivos manualmente.

Instalación y uso

  1. Haz clic en el indicador de agente (esquina superior derecha de la app) y selecciona Descargar zebralab_agent.py
  2. Guarda el archivo en una carpeta de tu Mac, por ejemplo: ~/Documents/zebralab/
  3. Abre Terminal y ejecuta:
    python3 ~/Documents/zebralab/zebralab_agent.py
  4. Verás el mensaje Escuchando en http://localhost:17331 y la lista de impresoras detectadas
  5. Vuelve a ZebraLab — el indicador cambiará a ● Agente conectado
Deja la ventana de Terminal abierta mientras uses la app. Puedes cerrarla con Ctrl+C cuando termines de imprimir.

Opciones avanzadas del agente

# Puerto personalizado
python3 zebralab_agent.py --port 17332

# Especificar impresora por defecto
python3 zebralab_agent.py --printer "Zebra_Technologies_ZTC_ZD220"

# Ver el nombre exacto de tu impresora en CUPS
lpstat -e

Configuración en ZebraLab

Al hacer clic en el indicador de agente puedes:

  • Seleccionar la impresora de la lista detectada
  • Cambiar el puerto si usaste uno distinto al predeterminado (17331)
  • Verificar la conexión con el botón Refrescar
Si accedes a ZebraLab desde una URL HTTPS (VPS), Chrome requiere que el agente responda correctamente a las peticiones de red privada. Usa siempre la versión más reciente del agente descargada desde la app.

9 Imprimir directamente

Con el agente activo, puedes imprimir sin descargar ningún archivo:

  1. Verifica que el indicador muestre ● Agente conectado
  2. Haz clic en Imprimir ahora
  3. Si tu diseño tiene variables, completa los valores en el modal
  4. Ajusta el número de copias
  5. Haz clic en Imprimir

Impresión directa (con agente)

  • Sin descargar archivos
  • Inmediata
  • Requiere agente activo en tu Mac

Exportar .prn (sin agente)

  • Descarga el archivo
  • Lo envías con lp o tu script
  • Funciona sin conexión

10 Preguntas frecuentes

¿Por qué la vista previa tarda un poco?

La vista previa usa el servicio público Labelary (api.labelary.com) para renderizar el ZPL como imagen. Depende de tu conexión a internet y la disponibilidad de ese servicio.

¿Puedo usar la app sin conexión a internet?

No. La app web y el servidor requieren conexión. Sin embargo, los archivos .prn exportados pueden usarse offline con tu script Python o directamente con lp.

¿Qué pasa si mi CSV tiene tildes o caracteres especiales?

ZebraLab soporta UTF-8. Guarda tu CSV con encoding UTF-8 (opción disponible en Excel al "Guardar como CSV UTF-8"). El ZPL generado usa ^CI27 (UTF-8).

¿Puedo usar el mismo diseño con distintos archivos CSV?

Sí. Guárdalo como plantilla y úsalo cuantas veces necesites con distintos archivos de datos.

¿El archivo .prn descargado es compatible con mi script Python anterior?

Sí. ZebraLab preserva los placeholders {variable} en el ZPL, idéntico al formato que usa tu script BoaIdeia original con lp -d NombreImpresora -o raw.

¿Cuántas etiquetas puede generar el lote?

No hay un límite fijo. Se recomienda no superar 5.000 etiquetas por lote para mantener tiempos de respuesta aceptables.

¿Puedo hacer etiquetas con 2 o más columnas?

Sí. En el panel de propiedades (sin elemento seleccionado) puedes configurar Múltiples etiquetas por tirada, definiendo columnas, filas y el espacio entre ellas.

¿El agente funciona en Windows o Linux?

El agente usa el comando lp de CUPS, disponible en macOS y Linux. En Windows requeriría adaptación para usar comandos de impresión distintos.
